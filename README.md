# STM32F103C8\_CAN-FIX

CAN-FIX implementation on an STM32F103C8 "Blue Pill"



Hardware Requirements:

STLInk-V2 (ST-Link V2 Emulator Downloader Programmer)

5V Power Supply (Temporarily may use STLink-V2 Power)

STM32F103C8 (STM32F103C8T6 ARM STM32 Minimum System Development Board Module STM32F103C8T6)

CAN Transciever (TJA1050 CAN Module CAN Bus Module CAN Bus Transceiver for STM32)



Software Requirements:

STMCubeIDE

STMCubeMx
